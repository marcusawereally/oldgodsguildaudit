# Contributing

Use GitHub Issues for reproducible bugs and feature requests. Include the addon version, game client, expected behavior, actual behavior and steps to reproduce. Remove account keys and private guild/player data from screenshots or logs before sharing them.

Pull requests are welcome for review. The maintainer integrates accepted changes into the combined development workspace, then publishes release snapshots here. Public `main` and version tags are updated by that release process; avoid relying on direct edits to an exported snapshot as the release source of truth.

Run `python3 validate-source.py` from the repository root for TOC/file checks. Also test affected UI and game API behavior in the appropriate WoW client; static checks do not prove live behavior.

Download the ZIP assets attached to a versioned release for installation. GitHub's automatic source archives include repository documentation and tooling.
